## Featured Projects

### 1. [taylor.c]

This program seeks to allow the user to have a nice way to validate the computation of a function f(x)=1/(1-x) by comparing it with the taylor series approximation on the console.
- **Skills demonstrated:** [loops, functions, input validation, error handling]
- **Source and details:** [`01-early-program/`](01-early-program/)

### 2. [receipt_writer.c]

This program is meant to be a way to track expenses from a purchase of cookies, a sandwich and coffee through File IO. I grew as a programmer as I shifted from expecting output to taking input, validating input, and writing to a persistent form of output in the form of a text file.
- **Skills demonstrated:** [ File IO, modular design, input validation]
- **Source and details:** [`02-midcourse-program/`](02-midcourse-program/)

### 3. BroBank
Brobank is a small command line based banking application that allows for persistent account management, creation of a bank log, transacations/withdrawls/transfers, undoing transactions, and tracking if a transaction has been made between two parties written in C.

- **Skills demonstrated:** [ queues, stacks, file persistence, testing, DFS/BFS transactions between two accounts, error handling]
- **Source and details:** [`03-brobank/`](03-brobank/)

## What I Learned

I learned how to write modular code, make design choices, and how to scale a program. This can be seen through the scaling of my program complexity from a simple terminal program to compute a taylor series to creating interactive banking applications that can be applied in real world scenarios One challenge I overcame was when I was debugging my brobank application and I realized the issue was not with the program but rather in my tests. This awareness is crucial as a programmer must be flexible and willing to think critically about problems. One skill I want to work on next is my understanding of backend frameworks and I intend to actualize this by building an HTTP server in C.
