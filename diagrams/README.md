# Diagram or Visualization

I added a diagram to help a reviewer understand my code. My choice was:

- A BroBank module or function diagram 

## Diagram Explanation

The diagram displays the structure of the components of brobank and the role they play in constructing the larger program.
They are split into header files, c files, and txt files which either have forward declerations, define an implementation or have input read or output written to. This is a nice way to understand my implementation as instead of reading through the specific implementation details we can abstract this to a high level overview of how each module performs in brobank.
